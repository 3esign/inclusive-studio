# Inclusive Studio — pilot

**Sajt: https://3esign.github.io/inclusive-studio/**

Kolaborativna pilot platforma: studenti 3. godine arhitekture i članovi udruženja osoba sa invaliditetom zajedno projektuju pristupačne prostore — šest nedelja, jedno stvarno mesto, korisnici kao koautori (ne „slučajevi").

## Kako radi
- **Sajt** nosi plan po nedeljama, živu tablu ideja i skicirnicu.
- Sve **ideje i nedeljne predaje** su GitHub Issues — tekst, fotografije i skice (prevuci sliku u formular). Sve je javno i otvoreno za komentare.
- Tabla ideja na sajtu čita uživo sa Issues API-ja; bez servera, bez build koraka, nula zavisnosti.

## Šest nedelja
1. **Posmatraj** — audit javnog objekta sa 7 principa univerzalnog dizajna.
2. **Upoznaj** — razgovor u paru sa članom udruženja ([vodič](docs/vodic-za-razgovor.md)).
3. **Izmeri** — zajednička šetnja; barijera postaje broj.
4. **Zamisli** — ko-dizajn radionica, 3 skicirane ideje.
5. **Razradi** — jedan koncept u razmeri, recenzent je korisnik.
6. **Pokaži** — korisnost ocenjuju korisnici, ne žiri.

## Uporište
Pedagogija prati dokaze: direktan, ravnopravan rad sa osobama sa invaliditetom je aktivni sastojak nastave pristupačnosti; pasivne simulacije invaliditeta se izbegavaju (merljivo pogoršavaju stavove). Uzori: MIT 6.811 (ceo semestar sa stvarnim klijentom), UW CSE 493E (ocenjivanje po kompetencijama).
